MCP 2026-07-28 Specification Finalises Today — Stateless Core, Breaking Changes

Source: Model Context Protocol Blog & The Register  |  July 28, 2026

Anthropic's Model Context Protocol publishes its most significant revision since launch today, delivering a fully stateless transport core that allows MCP servers to run behind ordinary round-robin load balancers rather than requiring sticky sessions or shared session stores. The update also introduces MCP Apps for server-rendered UIs, a Tasks extension for long-running background work, and OAuth/OpenID Connect-aligned authorisation — but ships with deliberate backward-incompatible breaks that will require both client and server implementors to migrate to the same protocol era. Source: cubbbix.com / Vorp Labs  |  July 2026

India published its draft Digital India Act on July 1, introducing a risk-based AI classification framework that mirrors the EU model but imposes stricter liability — including strict liability for AI-caused harm in critical AI categories, stronger than the EU AI Act standard.
