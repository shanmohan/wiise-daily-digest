Microsoft Agent Framework Moves AutoGen to Maintenance Mode as Unified SDK Matures

Source: mhtechin.com / futureagi.substack.com  ·  April–May 2026

Microsoft has formally merged AutoGen and Semantic Kernel into a single unified SDK called the Microsoft Agent Framework (MAF), targeting a 1.0 GA release in Q1 2026. Google's A2A Protocol Reaches v1.2 in Production at 150 Organisations Under Linux Foundation Governance

Source: The Next Web / a2a-protocol.org  ·  April 2026

Google's Agent2Agent (A2A) protocol — originally launched with over 50 technology partners — has now reached version 1.2 and is running in production (not just pilot) across 150 organisations including Microsoft, AWS, Salesforce, SAP, and ServiceNow. The protocol has been donated to the Linux Foundation's Agentic AI Foundation and now uses cryptographic signatures for domain verification on agent cards. A2A is designed to complement Anthropic's Model Context Protocol: MCP handles how an agent connects to tools and data sources, while A2A governs how agents communicate with each other across organisational and platform boundaries. Native A2A support is now built into Google ADK, LangGraph, CrewAI, LlamaIndex Agents, Semantic Kernel, and AutoGen.
