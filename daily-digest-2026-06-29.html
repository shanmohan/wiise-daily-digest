Source: LangChain.com / AliceLabs.ai  ·  Published: June 2026

Microsoft's unified orchestration SDK — the Agent Framework — reached 1.0 GA for both Python and .NET runtimes simultaneously on April 3, 2026, combining AutoGen's conversational multi-agent patterns with Semantic Kernel's enterprise-grade session management, middleware, and telemetry. Google ADK's A2A Protocol Enables Cross-Framework Agent Communication

Source: GuruSup.com / Cordum.io  ·  Published: May 2026

Google's Agent Development Kit, which launched in April 2025 and has matured significantly through H1 2026, offers a standout capability no other major framework yet matches natively: full support for the Agent-to-Agent (A2A) protocol, allowing an ADK agent to discover and invoke agents built with LangGraph, CrewAI, or any A2A-compliant framework through a standardised task interface. The hierarchical agent tree model — a root agent delegating to sub-agents with their own sub-agents — integrates tightly with Vertex AI, Gemini models, and Google Cloud services, making it the natural default for GCP-native engineering teams. For organisations evaluating multi-vendor agentic stacks, A2A interoperability is rapidly becoming a procurement criterion rather than a nice-to-have.

Source: VerifyWise.ai / Gunderson Dettmer  ·  Published: May–June 2026

With federal legislation stalled and the Trump administration's December 2025 Executive Order signalling intent to pre-empt state rules, enterprises operating across multiple jurisdictions face an increasingly fragmented and rapidly shifting compliance landscape.
