Protocol

Google's A2A Protocol Hits 150 Production Organisations, Governed by Linux Foundation

The Next Web • May 2026

Google's Agent2Agent (A2A) protocol — originally launched with 50 technology partners — has rapidly scaled to real-world deployments and achieved a significant governance milestone. Google's A2A protocol has reached 150 organisations in production (not pilot) routing real tasks between agents built on different platforms; the protocol is now governed by the Linux Foundation's Agentic AI Foundation and has reached version 1.2, with signed agent cards using cryptographic signatures for domain verification. Major enterprise software vendors are already running it in live environments: Microsoft, AWS, Salesforce, SAP, and ServiceNow are running A2A in production environments.

The relationship with Anthropic's Model Context Protocol (MCP) is deliberately complementary rather than competitive. A2A is designed to complement rather than compete with MCP — MCP handles how an agent connects to tools and data sources, while A2A handles how agents communicate with each other across organisational and platform boundaries. This two-layer interoperability stack is rapidly becoming the de-facto standard for multi-vendor agentic deployments.

AutoGen / AG2

AutoGen Reaches v0.4.5 Stability — but Token Cost Risks Remain a Production Warning

DasRoot Technical Review • April–May 2026

Microsoft's AutoGen framework has reached a stable milestone, though practitioners are advised to instrument usage carefully before deploying at scale. As of 2026, AutoGen has reached stable version v0.4.5, with operational costs averaging $0.35 per query and 70% production uptime according to Microsoft benchmarks. The conversational GroupChat architecture that defines AutoGen is also its primary financial risk: AutoGen conversation loops are the biggest cost risk in production — without hard termination conditions, open-ended agent debates can consume 5–10× the expected tokens.

The framework's competitive niche continues to be research-oriented and Azure-native deployments. Microsoft's research teams have used AutoGen for multi-agent research workflows, achieving 25% productivity gains; however, its higher token usage and CPU footprints (up to 2.5 GB) make it more resource-intensive than other frameworks. Teams building on Azure with human-in-the-loop requirements should note AutoGen's strong enterprise backing despite the overhead tradeoffs.

Coding Agents

Claude Code Reaches $1B ARR and 80.9% SWE-bench Score — Sets the Benchmark for Agentic Coding

Kanerika / Scrimba • May 2026

Claude Code has rapidly moved from niche terminal tool to the recognised benchmark for agentic software engineering quality. The tool's architectural philosophy sets it apart from IDE-native competitors: Anthropic frames Claude Code as operating "at the project level" rather than line by line — it reads the codebase, plans a sequence of actions, executes them with real development tools (git, package managers, language tooling), evaluates the result, and adjusts.

The primary trade-off remains cost: for a 5-developer team on heavy agentic usage, Claude Code's Max plan can run $500/month versus Windsurf Team at approximately $100/month.
