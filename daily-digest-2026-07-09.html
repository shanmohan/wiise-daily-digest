1. Agentic AI & Frameworks

Microsoft Unifies AutoGen and Semantic Kernel Into a Single Agent Framework at GA

Source: LangChain.com / Microsoft — Published June 2026

Microsoft's Agent Framework — the unified successor to AutoGen and Semantic Kernel — shipped its Python and .NET runtimes simultaneously at 1.0 GA on April 3, 2026, bringing both code-bases under one roof with declarative YAML agent configuration and migration assistants for teams on either predecessor platform. The framework combines AutoGen's conversational multi-agent coordination with Semantic Kernel's enterprise-grade session management, middleware, telemetry, and type safety, while adding graph-based workflows for explicit control over multi-agent execution paths. Teams still on AutoGen or Semantic Kernel will continue to receive security and bug-fix support during the support window, but Microsoft is directing all new long-term investment toward the unified SDK, including native MCP and A2A 1.0 protocol support.

Google ADK's A2A Protocol Emerges as Cross-Framework Interoperability Standard

Source: GuruSup.com — Published May 2026

Google's Agent Development Kit (ADK), released in April 2025, has matured into a hierarchical agent runtime with a standout differentiation: native support for the Agent-to-Agent (A2A) protocol, enabling agents from entirely different frameworks — including LangGraph and CrewAI — to discover and invoke each other through a standardised task interface. The framework integrates tightly with Vertex AI, Gemini models, and the broader Google Cloud services ecosystem, making it the natural choice for GCP-native teams that want opinionated, batteries-included agent infrastructure with built-in debugging UIs. For multi-framework environments, A2A is rapidly emerging as the cross-vendor interoperability layer that reduces vendor lock-in at the orchestration level.

🔗 https://gurusup.com/blog/best-multi-agent-frameworks-2026

Production Governance Gap Widens: Agent Frameworks Alone Are Not Enough for Enterprise Deployment

Source: Cordum.io — Updated June 2026

A detailed mid-2026 analysis of LangChain, CrewAI, AutoGen, LlamaIndex, and Semantic Kernel concludes that while each framework shapes agent behaviour effectively in development, none provides a complete production governance layer on its own — a gap that is increasingly consequential as agents gain access to production systems. Before autonomous agents can modify infrastructure, send customer data, approve spend, or execute transactions, teams still require policy-before-dispatch gates, explicit human approval states, and auditable evidence trails that exist outside the framework itself. The analysis recommends pairing any agent framework with a dedicated Agent Control Plane for policy enforcement, approvals, and audit capture as a baseline production requirement.
