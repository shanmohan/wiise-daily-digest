Microsoft Agent Framework Reaches 1.0 GA, Unifying AutoGen and Semantic Kernel New

Source: LangChain.com / Microsoft — Published June 2026 (3 weeks ago)

Microsoft officially launched the Microsoft Agent Framework (MAF) at 1.0 GA in both Python and .NET runtimes simultaneously on April 3, 2026, replacing AutoGen and Semantic Kernel as the company's single recommended orchestration path. The framework merges AutoGen's conversational multi-agent design with Semantic Kernel's enterprise-grade session management, middleware, telemetry, and type-safety, and layers on graph-based workflow control for deterministic multi-agent execution. Existing AutoGen and Semantic Kernel projects will continue to receive bug fixes during their support windows, but new development and long-term investment should target MAF, which ships with native MCP and A2A protocol support ahead of the forthcoming A2A 1.0 specification.

Google ADK's A2A Protocol Enables Cross-Framework Agent Interoperability Watch

Source: GuruSup.com / Google — Published May 2, 2026

Google's Agent Development Kit (ADK), released in April 2025, has emerged as a compelling enterprise option for teams on Google Cloud, offering a hierarchical agent tree where a root orchestrator delegates tasks to nested sub-agents with tight Vertex AI and Gemini model integration. Its standout capability is native support for the Agent-to-Agent (A2A) protocol, which enables a Google ADK agent to discover and invoke agents built on entirely different frameworks — including LangGraph and CrewAI — through a standardised task interface, making it the first major framework to treat cross-vendor agent interoperability as a first-class feature. The framework also ships with built-in debugging UIs and is the recommended pick for GCP-native organisations seeking an opinionated, batteries-included runtime.

https://gurusup.com/blog/best-multi-agent-frameworks-2026

CrewAI Integrates NVIDIA NemoClaw for Infrastructure-Level Policy Enforcement New

Source: MHTECHIN Technologies — Published June 2, 2026

Early 2026 saw CrewAI announce a deep integration with NVIDIA's NemoClaw stack, targeting regulated enterprise deployments that require security guarantees beyond what agent-level code alone can provide. The key innovation is that security policies are now enforced at the infrastructure runtime layer rather than within agent logic itself — meaning that even if an agent's internal reasoning or code changes unexpectedly, the runtime will still block any action that violates defined policy. A benchmark suite of 2,000 runs revealed that while CrewAI consumes significantly more tokens than LangGraph for simple tasks, it performs comparably on complex multi-step scenarios, and with NVIDIA's infrastructure-level controls it now addresses the governance gap that previously made it unsuitable for production in sensitive industries.

2026 Framework Decision Guide: Governance Is Now the Differentiator, Not Feature Sets Report

Source: Cordum.io — Updated June 2, 2026

A practitioner-focused comparison published this month reframes the agent framework debate: while LangChain, CrewAI, AutoGen, LlamaIndex, and Semantic Kernel all deliver capable orchestration loops, none of them is a complete production governance layer on its own. Before an autonomous agent can modify infrastructure, transmit customer data, approve expenditure, or execute transactions, teams still need policy-before-dispatch controls, explicit human approval states, and a full audit evidence trail — capabilities that must be layered on top of any framework. The report recommends pairing the framework best matched to your workload shape with a dedicated Agent Control Plane, and rates frameworks not merely on quickstart speed but on state durability, failure recovery, and compliance integration.
