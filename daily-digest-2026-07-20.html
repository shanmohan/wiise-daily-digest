Microsoft Agent Framework Reaches GA, Unifying AutoGen and Semantic Kernel

Source: LangChain.com / JetBrains Blog  ·  Published: June–July 2026

Microsoft has officially consolidated its two most prominent agent projects—AutoGen and Semantic Kernel—into a single, production-ready SDK called the Microsoft Agent Framework, which shipped both Python and .NET runtimes simultaneously at 1.0 GA on April 3, 2026. The unified framework brings together AutoGen's conversational multi-agent abstractions with Semantic Kernel's enterprise-grade session management, telemetry, and type safety, and layers on graph-based workflow orchestration for fine-grained control over multi-agent execution paths. Teams already running on either predecessor are directed to migrate via published guides, with bug-fix and security support continuing during a defined transition window, and new development should begin on the consolidated framework to benefit from native MCP and emerging A2A 1.0 support.

LangGraph Surpasses CrewAI in GitHub Stars as Enterprise Production Adoption Grows

Source: Medium / AliceLabs.ai  ·  Published: April–July 2026

LangGraph, the graph-based orchestration layer built on top of LangChain, overtook CrewAI in GitHub stars during early 2026, driven by enterprise teams that value its directed-graph architecture, explicit state management, built-in checkpointers, and time-travel debugging for production audit trails. Its design—where agents are nodes, state flows along typed edges, and conditional branching is a first-class concept—maps cleanly to compliance-sensitive workflows requiring rollback points and human-in-the-loop approval at any execution step. CrewAI retains its edge for rapid prototyping with a role-based crew model, but a well-documented migration pattern has emerged where teams graduating from prototype to production almost inevitably move from CrewAI to LangGraph for state management and conditional routing.

Google ADK and A2A Protocol Emerge as the Interoperability Layer for Cross-Framework Agents

Source: GuruSup.com / PEC Collective  ·  Published: May 2026

Google's Agent Development Kit (ADK), released in April 2025 and now widely adopted in 2026, introduces a hierarchical agent-tree model where a root orchestrator delegates to nested sub-agents, with native support for the Agent-to-Agent (A2A) protocol enabling cross-framework discovery and invocation. Through A2A's standardised task interface, an ADK agent can call out to a LangGraph agent or a CrewAI crew without bespoke integration code, positioning the protocol as the emerging interoperability standard across the fragmented ecosystem. For GCP-native organisations, ADK is increasingly the recommended batteries-included runtime, offering a built-in debugging UI and tight Vertex AI and Gemini model integration out of the box.
