MCP and A2A Protocols Now Under Linux Foundation Governance, Reshaping Agent Interoperability

daily.dev / Google ADK / Medium — April–May 2026

The Model Context Protocol (MCP) has reached widespread adoption with over 5,800 public MCP servers in operation as of March 2026, with 70% of major SaaS brands offering remote MCP endpoints — making it a universal integration layer across all major agent frameworks. Alongside it, Google's Agent-to-Agent (A2A) protocol enables cross-framework agent collaboration, where a LangChain research agent and a CrewAI writing agent can now discover each other's capabilities via Agent Cards (JSON manifests at /.well-known/agent.json) without custom glue code. Both protocols are now under Linux Foundation governance, creating a standardised three-layer architecture that the industry is coalescing around.

Google's ADK, released in April 2025, further leverages A2A natively, allowing ADK agents to invoke agents built with LangGraph or CrewAI through a standardised task interface — establishing the foundations for a true multi-framework enterprise agent mesh.
