Protocols

MCP Becomes the De-Facto Agent Wire Standard as OpenAI, Google, and Salesforce Align

Vertu.com / Zylos Research / morphllm.com — July 2026

The most consequential infrastructure shift of 2026 may be largely invisible to end users: Anthropic's Model Context Protocol (MCP) has become the shared wire format connecting AI clients to external tools, with OpenAI's Apps SDK now built directly on top of it. This means a tool or integration built once against the MCP specification can run across ChatGPT, Claude, Gemini, GitHub Copilot, and Cursor without per-vendor engineering overhead — a genuine unlock for enterprise development teams managing multi-model environments. Complementing MCP is Google's Agent-to-Agent (A2A) protocol, now under Linux Foundation governance, which handles inter-agent communication and delegation; together, MCP and A2A are solidifying as the two-layer reference architecture for production agentic systems, with MCP covering vertical tool integration and A2A enabling horizontal agent coordination.
